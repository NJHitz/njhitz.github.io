NJ Hitz GameChanger Profile Helper 1.0.0 — Chrome / Edge

1. Download and unzip the helper into a folder you will keep.
2. Open chrome://extensions (Chrome) or edge://extensions (Edge).
3. Enable Developer mode, choose Load unpacked, and select that folder.
4. Reload the NJ Hitz management page after installation and sign in.
5. In your own authorized GameChanger account, open the team's Stats page.
   Clear game filters to show the entire season. The CSV export must be
   available; GameChanger currently restricts export to team Staff accounts.
6. Open the helper, enter the player's GameChanger URL, name/jersey, team,
   season label and season end date. Confirm the source and capture the export.
7. Select the correct open NJ Hitz player management page and Send.
8. Return to NJ Hitz, confirm the capture, Import season into draft, and Submit
   for review. Staff compares the source and approves before publication.

CSV fallback: export the original GameChanger CSV and choose it directly in
NJ Hitz. Keep its two section/header rows. Only the matching player's selected
batting/pitching values are sent; other players' CSV rows remain in the browser.

The helper does not store or transfer your GameChanger login credentials,
cookies, or session tokens. It reads the existing CSV export only after you
click Capture. Selected captures stay in extension session storage until the
browser closes. It does not run background synchronizations. Re-capture and
submit again to refresh a season. Each GameChanger team/player pair identifies
one season row; different teams/seasons are retained separately.

Known limitation: live page capture still requires verification against the
current signed-in GameChanger layout. If GameChanger changes its export control,
use the CSV fallback while the helper is updated. This is an NJ Hitz tool and is
not affiliated with or endorsed by GameChanger.
